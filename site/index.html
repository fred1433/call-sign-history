Change the rule on your own machine

The same decisions come from one Python file with no dependency and no model. Edit a rule in reconcile.py, run it again, and the comparison lists every line that moved.

git clone https://github.com/fred1433/call-sign-history cd call-sign-history python3 reconcile.py --compare

It writes out/decisions.csv, one row per line with its decision, its reason and the source of each value, and prints the counts shown above. 14 tests cover the Seattle case, the abstentions, and check that this page shows the same counts as the command. Open the repository.
