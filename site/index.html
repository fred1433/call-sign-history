The broadcast table in Appendix A of the same FCC order lists 1,074 licenses. We hid the facility ID column, matched every line against today's FCC registry and the FCC's own call sign history, then checked each decision against the hidden column. 947 lines are full-power AM or FM; the rest stay out of scope.

One line the dated rule cannot settle: KUUL(FM), East Moline, IL

The order prints facility 43208 next to it. Our history extract doesn't place KUUL in Illinois on that date: CDBS gives KUUL to 60596 in Gallup, NM from 1985 and to 43208 only from June 29, 2010. Two FCC documents disagree with that date, so the line stays in review with 60596 as the only candidate, and a person decides.

Change the rule on your own machine

The same decisions come from one Python file with no dependency and no model. Each run writes out/decisions.csv and lists the lines that changed since the previous run, so you can edit a rule in reconcile.py, run it again, and see what moved.

git clone https://github.com/fred1433/call-sign-history cd call-sign-history python3 reconcile.py --rule today rule=today accept_undated=False require_city=False list date=2008-01-24 ... Linked, wrong facility 32 ... first run: run again after changing a rule to see which lines move python3 reconcile.py rule=dated accept_undated=False require_city=False list date=2008-01-24 ... Linked, wrong facility 0 ... 359 lines changed since the previous run A0001 WDDD(AM) Johnston City, IL: No candidate in this snapshot -> Review (...)

Lines shown as ... are cut here, not in the output. 21 tests cover the Seattle case, the abstentions, the parser, the diff between runs, and check that this page shows the same counts as the command. Open the repository.
